# 界面设计

GHub 面向手机上的远程开发工作。界面围绕项目、会话和当前任务组织，让阅读、输入和常用操作保持连续。主要实现使用 Jetpack Compose 与 Material 3。

## 导航与入口

首页按服务器展示项目。项目行在名称下显示会话数与最近活动时间，项目展开后显示最近会话；会话标题与项目名对齐，下方显示相对更新时间。会话状态只标注需要关注的情况：新结果、运行中、失败、待确认和待回答；已读的完成会话不加标签。左上角切换服务器，右上角提供添加项目、归档筛选和设置。添加、编辑、删除服务器与连接管理统一在设置中完成。

服务器列表只显示名称和连接状态。服务器详情使用轻量概览：标题栏右侧只有一个连接按钮，同时表达当前状态和下一步操作。离线点击连接，在线点击断开，连接或重连中点击取消；长按说明和读屏标签包含状态与操作，错误原因直接显示。下方为连接信息、身份验证、跳板机、远端 Codex 四个入口；省略重复的字段说明及“默认”“直连”摘要，地址与完整跳板链进入编辑后查看。在线时通过“远端环境”查看账号和服务版本，避免常驻技术文字。

连接编辑首页直接显示名称、地址、用户名；端口、身份验证、跳板机和远端配置独立进入，避免一次展开所有表单。认证使用纵向单选项，跳板机按连接顺序列出且一次编辑一台。各页共享同一草稿，只在连接配置首页保存；子页返回保留修改，退出编辑器时确认丢弃未保存修改。保存校验自动进入缺失字段所在页面并聚焦，保存期间禁止重复修改与返回。草稿元数据和当前位置可恢复；密钥、密码、口令只驻留内存或加密存储，不进入 SavedState。

项目菜单提供会话、文件和终端入口。聊天页的更多菜单提供项目工具与会话操作，从文件或终端返回时回到原来的会话。服务器详情负责配置和连接状态，项目操作由工作台承载。

模型、思考级别、服务器和项目等选择使用共享底部面板。长列表可滚动，当前选项有勾选标记；同名项目显示路径辅助区分。

## 聊天与任务状态

助手回复按连续正文排版，不加作者标签；用户消息使用独立表面。命令、计划、推理摘要和失败输出默认收起，展开执行过程后查看详情；运行中，执行过程摘要显示当前命令。任务结果与连接同步状态分别展示，常态状态使用图标，异常和待处理状态保留文字。完成状态只在回复操作行出现一次；同步徽章只在实时接收、对账中或离线时出现，「已同步」是默认状态，不再显示。

文件摘要默认展示前三项，其余可展开；同名文件附父目录，完整路径和 Diff 可继续查看。回复提供复制和系统分享，长文本可分享为 Markdown 文件。

审批卡片使用琥珀色边条与底色，操作为「允许一次 / 拒绝并继续 / 中止任务」。审批或阻塞问题滚出可读区域时，输入框上方显示固定横幅，点按滚动到对应卡片。加载历史时，进度条叠加在顶栏下沿，不改变对话布局。

首次打开会话定位到末尾。阅读历史时暂停跟随，显示「最新」入口；发送消息后恢复跟随。输入法和流式内容变化时，布局依据用户当前的跟随状态调整位置。

## 输入与选择面板

输入框最多显示五行，并随可用高度调整。附件位于文字上方，上传、模型、思考级别、语音和发送操作位于下方。窄屏或大字体下，模型和思考级别合并为一个入口。

输入框文本区与工具栏使用同一纯色表面。运行中，发送按钮变为红色停止按钮。

语音识别结果进入草稿。离线、审批等待和发送待确认状态分别显示对应操作状态，草稿保持可编辑。

共享选择行最小高度为 52dp，左右边距为 24dp，右侧预留 20dp 勾选位置。服务器名称和状态在窄屏或大字体下分行展示。模型列表与思考级别来自服务器返回的能力。

## 文件

路径单行显示，过长时省略中段。文件夹在第二行显示修改时间，文件显示大小和修改时间。排序为文件夹在前、文件在后，隐藏项（以 `.` 开头）排在同类之后并减淡显示。

## 代码与命令

`CodeBlock` 复用于执行命令、审批、Markdown 代码和 Diff：

| 内容 | 默认呈现 |
|---|---|
| 命令 | 自动换行，复制按钮位于命令右侧，不单独占一行标题 |
| 输出 | 自动换行，命令与输出分别复制 |
| 源码、Diff | 横向滚动，可切换换行 |
| 长内容 | 短预览与全屏阅读器，全屏按段加载 |
| 已支持语言 | 基础词法高亮 |
| 其他语言 | 等宽纯文本 |

代码使用 13sp / 20sp 的字号与行高，横向留白 12dp。工具栏中的换行开关是图标切换按钮，开启时带强调底色。执行信息只显示非零退出码；耗时按 毫秒 / 秒（一位小数）/ 分秒 显示。高亮覆盖 Shell、JSON/JSONC、Python、JavaScript/TypeScript、Kotlin/Java、YAML 和 Diff，输出支持常见 ANSI 前景色。复制始终使用原文。

解析在后台运行，流式更新合并处理；收起内容或离开页面时释放对应任务。

## 终端

终端使用独立顶栏，点击名称切换会话。会话面板展示完整项目名称和路径，并提供新建与关闭操作。正文四周保留空间：常规布局左右 8dp、上下 6dp。

底部默认显示 Esc、Tab、Ctrl 和方向键，方向键按 ← ↑ ↓ → 排列。Alt、Shift、Home、End 与粘贴从菜单展开；修饰键点按用于下一次输入，长按锁定，再点按解除；用法提示在首次使用修饰键后隐藏。激活状态同时提供视觉标记和无障碍描述。

字号支持 10–28sp、双指缩放和恢复默认，字号与扩展键盘偏好保存在本机。快捷键通过 `TerminalView` 编码，遵循应用光标模式。

输入法占位后的可用高度不足 240dp 时收起顶栏；不足 120dp 时收起底部快捷栏，侧边保留隐藏键盘和激活修饰键入口。键盘收起后恢复正常布局。终端行数随实际显示区域更新，最少两行。

## 图标

全界面统一使用 Phosphor Icons 2.1.1 的 Bold 字重，直接使用 Bold 原稿，保留原始矢量路径、填充规则与 256 单位网格，不额外叠加描边；以原生 Compose ImageVector 绘制，不依赖图标字体。操作图标通常为 20dp，状态图标为 16dp，触控操作保持至少 48dp。

设置使用齿轮，外观使用明暗圆，连接使用插头/断开的插头，服务器使用机架，执行使用终端，编辑使用铅笔，跳板机使用层级连线，数据使用数据库。实时接收使用脉冲，同步完成使用双勾，与连接状态分开表达。正常连接、任务完成和复制反馈保持中性灰；失败、待审批与未读结果才使用状态强调色。

## 会话内容操作

复制、分享、编辑和全屏查看共用轻量图标按钮：20dp Phosphor Bold 图标、48dp 点击区域、中性前景色，默认无底色。中英文界面使用相同布局，长按提示和无障碍名称说明具体操作对象；复制公式得到 LaTeX，复制表格得到 Markdown，代码、输出和消息保留原文。

所有复制入口统一显示约 1.8 秒的勾选反馈并提供轻触反馈；重复点击重新计时，内容更新后清除旧反馈。按钮名称保持稳定，通过状态描述播报“已复制”，图标切换不改变布局尺寸。超长回复继续引导使用分享保存完整文件。

代码与表格的操作位于顶部右侧，全屏查看使用同一个图标。公式的复制位于同一行右上侧，与可横向滚动的内容分开测量，不遮挡公式。消息级操作位于消息底部。显示更多行、加载历史和审批等需要说明含义的操作保留文字。

## 色彩、字体与动效

界面以中性灰阶区分层级，蓝灰色用于操作、选中和状态。连接状态在各界面使用同一套图形和颜色：在线为中性灰插头，连接或同步中为蓝色循环箭头，需要处理为红色错误图标，未连接为灰色断开插头。正文使用透明背景，输入框、用户消息、代码和选择项使用不同的 Material 表面角色。

聊天正文采用紧凑的 15sp / 24sp 排版，段落间距 8dp。主要触控目标至少 48dp，文本支持系统字体缩放；名称与路径在详情和选择面板中可完整阅读。

背景模糊用于顶部栏和输入工具栏等浮层。Android 12 及以上使用 Haze / RenderEffect，Android 10–11 使用高不透明度表面。项目展开与收起沿用系统动画设置，连续操作可以反向打断动画。

输入法边距由共享视口管理，底部提示位于操作区上方。系统返回、边缘手势和底部面板关闭遵循 Android 的导航习惯。

## 预览与检查

离线预览复用真实组件，入口见[开发指南](development.md)。界面改动重点检查深浅色、320dp 窄屏、200% 字体、横屏键盘、选中状态与返回路径。自动回归和真机检查方法见[测试指南](verification.md)。

## 数学公式

会话支持 `$…$`、`\(…\)` 行内公式和 `$$…$$`、`\[…\]` 独立公式。公式通过 JLaTeXMath Android 原生绘制，不依赖网络或 WebView。分数、上下标、根号、求和、积分和矩阵可与 Markdown 列表、表格混排；代码和链接地址中的公式标记保持原样。

公式随主题颜色和系统字体大小调整，不加常驻底色。独立公式保留自然尺寸，过宽时横向滚动，并提供 LaTeX 源码复制；行内公式过宽时在段落可用宽度内滚动。整条回复的复制/分享仍保留原始 Markdown。

流式输出中未闭合的公式、语法错误或不支持的命令显示源码。公式在后台串行排版并缓存，不支持改变全局 TeX 状态的宏定义、外部图片或完整 LaTeX 文档；超过 4096 字符或绘制尺寸上限的公式也回退到源码。

### 常态状态提示

- 顶栏、服务器列表/切换面板、连接详情和终端的正常连接使用插头图标；保留服务器、项目名称，不常驻“已连接”文字或彩色胶囊。
- 会话、工具和命令的完成状态，以及正常的输出同步状态使用轻量图标。任务完成与连接/同步状态分别表达，断网不改变任务结果。
- 图标使用同一图标库，16dp 图形居于 24dp 区域，无按钮底色；提供本地化读屏标签、长按说明。服务器选中标记独立于连接图标。
- 失败、断开、重连、等待网络、审批、提问等需要注意的状态保留文字；未读结果和汇总数量、连接/重试等操作仍保留清晰文案。
