# 使用指南

## 安装

从 [GitHub Releases](https://github.com/iawnix/GHub/releases/latest) 下载 `ghub.apk`，在 Android 10 或更新版本上安装。正式版使用相同签名，可直接覆盖升级。每个版本附带源码包和 `SHA256SUMS` 校验文件。

## 准备开发机

开发机需要 Linux、SSH 服务，以及 Codex CLI 0.164.0 或更新的 0.x 版本。文件操作需要服务器启用 SFTP。

以准备在手机上连接的同一个 Linux 用户完成 Codex 登录或模型提供方配置，然后运行：

```sh
codex --version
codex app-server daemon bootstrap
codex app-server daemon version
```

`bootstrap` 配置官方常驻服务，也可以从 GHub 的连接引导中执行。模型认证和提供方设置由开发机上的 Codex 管理。

要在电脑与手机之间接续会话，让电脑端 CLI 连接同一个 daemon：

```sh
codex --remote unix://
```

SSH 用户、Codex 配置目录和 daemon 需要一致；使用 `--no-daemon` 启动的独立会话不属于这个共享服务。

## 添加服务器

1. 打开「设置 → 服务器」，添加服务器名称、地址、端口和用户名。
2. 选择私钥、密码或键盘交互认证。私钥可设置口令；跳板机按实际连接顺序逐级添加。
3. 填写 Codex 可执行文件路径和默认工作目录。
4. 连接时，将显示的 SHA-256 主机指纹与服务器管理员提供的指纹核对。

通过 npm 或用户级工具安装的 Codex 可能不在 SSH 非交互环境的 `PATH` 中。遇到「找不到 Codex」时，填写可执行文件的绝对路径，例如 `/home/user/.local/bin/codex`。

首页左上角切换服务器；添加、编辑和连接管理统一位于设置。

## 项目与会话

项目按服务器和远端目录组织。可手动添加项目，也可从加载的会话中发现项目。展开项目后，点击会话继续工作，或新建会话开始任务。

手动添加项目时，App 会连接服务器并创建缺失的目录（包括父目录）；已有目录直接复用。目录确认成功后才保存项目入口。权限不足或路径被文件占用时，表单会保留输入并显示错误。重命名项目只修改本机显示名称。

聊天页支持模型和思考级别选择、图片与文件附件、系统语音输入、审批和停止任务。命令执行过程可展开查看，命令、输出和回复代码均支持复制；长内容可进入全屏阅读器。

向左或向右滑动会话可归档，并可撤销。项目菜单中的「从首页移除」只隐藏本机入口，会话和远端文件仍保留。

## 文件与终端

从项目菜单或聊天页更多菜单进入文件和终端，返回时继续原会话。

| 功能 | 使用方式 |
|---|---|
| 文本编辑 | 支持 1 MiB 以内的 UTF-8 文件；保存前检查远端内容是否变化 |
| 图片预览 | 支持缩放和拖动，单张图片上限 20 MiB；更大的文件可下载后打开 |
| 附件上传 | 保存到项目目录下的 `.remote-gpt/attachments/`，可按项目需要加入 `.gitignore` |
| 多终端 | 点击顶栏终端名称切换、新建或关闭会话 |
| 快捷键 | Ctrl、Alt、Shift 点按用于下一次输入，长按锁定，再点按解除 |
| 字号 | 在终端菜单中调整，或用双指缩放 |

新终端从项目目录启动。需要让 shell 程序跨断线继续运行时，使用远端 tmux，例如 `tmux new -As work`。

文件保存通过内容校验和临时文件原子替换完成，需要 SFTP 服务支持原子重命名。同时在多个编辑器修改同一文件时，建议先重新加载再保存。

## 连接与后台

网络恢复或 App 回到前台后，GHub 会检查连接并同步原会话。发送过程中断线时，消息可能显示「发送状态待确认」；先核对会话历史，再决定是否重新发送。

关闭后台保持时，App 退到后台 30 秒后释放连接和终端，回到前台自动重连。开启后台保持后，连接由前台服务维护，持续时间仍受系统电量和后台策略影响。远端 Codex 任务由 daemon 管理；普通 shell 任务可用 tmux 保留。

任务状态和完成提醒在连接期间同步。详细机制见[连接与同步](connection-recovery.md)。

## 常见问题

### 连接成功后看不到电脑上的会话

检查 SSH 用户、Codex 配置目录和 daemon 是否与电脑端一致。会话列表分页加载，较早的会话可通过继续加载查找。

### 文件保存提示冲突

远端文件已被其他程序修改。重新加载并合并改动后保存；需要替换远端内容时，使用界面提供的覆盖操作。

### 语音按钮不可用

语音输入依赖 Android 系统识别服务。检查服务是否安装、麦克风权限是否开启；识别是否联网由所选服务决定。识别结果会先进入草稿。

### 需要反馈连接异常或闪退

在「设置 → 导出诊断记录」保存日志，并在 [Issues](https://github.com/iawnix/GHub/issues) 中附上应用版本、Android 版本和复现步骤。公开日志或截图前，请检查其中的主机地址、路径和个人内容。
