GHub 0.1.41 支持会话中的交互提问，优化手机端同步与缓存，并修复新建工作区未创建远程目录的问题。

## 改进与修复

- 支持在手机上回答 Codex 的交互提问，并正确显示历史中的提问回复。
- 修复流式输出、历史刷新、断线重连和缓存恢复之间的覆盖问题，保留完整消息；长回答持续输出期间定期保存，完成时立即保存。
- 统一会话同步调度，根据前后台、会话活动状态和失败情况调整查询频率，减少重复请求与空闲轮询。
- 合并可见会话的连续文字更新，隐藏会话的文字增量不再单独触发界面更新；导航、提问、审批和完成状态仍及时显示。
- 缓存按变化的消息增量写入，减少长会话中的重复序列化与写入；兼容已有缓存，升级后自动迁移。
- 新建工作区时先在服务器创建并验证目标目录及缺失的父目录，再保存工作区。已有目录直接复用；路径被文件占用、权限不足或连接失败时保留表单并显示错误。旧版本遗留的缺失目录可通过重新添加同一路径修复。
- 诊断记录新增请求量、RPC 数据量、界面更新和缓存写入计数，便于排查资源消耗。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.41`，versionCode `42`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.40`。

本地验证覆盖单元测试、Android Lint、缓存数据库迁移与事务回滚、交互提问界面、持续流式输出及前后台恢复。真实 SSH 集成测试和 Android 工作区创建测试验证了远程目录创建、特殊字符路径、已有文件保护与失败后重试。发布流程还检查 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行。

手机端更新合并不会减少服务器已经发送的事件流量；实际耗电取决于设备、网络和会话活动情况。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
