GHub 0.1.45 优化会话页的长回复渲染和流式助手消息显示。

## 新增与改进

- 会话列表按用户消息、助手 Markdown 块、执行摘要、图片、文件摘要和回复操作拆分，长回复可以按列表条目懒加载，流式更新只影响变化中的块。
- 一轮中多条助手消息按原顺序持续显示，后续助手消息出现时，已经显示的进展不会缩回执行摘要。
- 自动跟随以最后一个真实内容条目为目标，移除末尾占位条目，减少长回复滚动和布局副作用。
- 保留命令、推理和工具事件的紧凑执行摘要；回复操作只绑定到最后一条完整助手消息。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.45`，versionCode `46`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.44`。

本地已通过 63 个 JVM 单元测试、Android Lint 和 Debug APK 构建；新增 `ConversationRowsTest` 覆盖多个助手消息的稳定顺序和回复操作归属。发布流水线还会检查 API 29/35/36 设备回归、API 35 精简 Release 运行和正式 APK 签名。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
