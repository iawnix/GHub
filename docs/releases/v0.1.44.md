GHub 0.1.44 支持停止任务后修改输入，并完善动态工具调用与上下文整理的执行记录显示。

## 新增与改进

- 最新任务确认停止后，点击用户消息下方的铅笔，将原文及附件载入底部现有输入框；顶部显示编辑提示和取消入口，发送仍使用原来的圆形箭头。中英文、窄屏和大字体沿用一致的操作位置。
- 编辑时恢复本机保存的附件、模型和思考级别；普通输入草稿单独保留，取消编辑或重发成功后恢复。重发创建新轮次，原消息和执行记录保留。
- 发送前检查远程附件和会话状态；附件失效或其他客户端已推进会话时，保留编辑稿并阻止重发。发送中及交付不确定时锁定输入，防止重复发送。
- `dynamicToolCall` 显示工具名称、参数、状态、耗时和返回内容，支持复制文本与媒体地址；工具返回失败时正确标记失败，不再只显示类型占位提示。
- `contextCompaction` 显示正在整理或已整理状态，兼容旧缓存；刷新活动任务历史时保留已确认完成的整理状态。
- 修复编辑状态切换时迟到的语音回调可能写入其他草稿的问题，以及输入框高度变化时自动滚动可能触发的布局重入。

停止前已产生的文件改动不会回滚。旧消息或其他客户端发送的消息缺少本机输入快照时，保留历史文本和明确记录的图片路径。动态工具的旧缓存详情需联网刷新后恢复。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.44`，versionCode `45`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.43`。

本地已验证中英文编辑界面、320dp 窄屏与 1.5 倍字体，并通过隔离 SSH / App Server 回归检查草稿持久化、附件失效、重复点击、历史保留和多客户端推进。发布流水线检查 JVM 单元测试、Android Lint、API 29/35/36 设备回归、API 35 精简 Release 运行与正式 APK 签名。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
