GHub 0.1.59 修复会话审批卡片在内容更新时的显示重叠，并改善后台任务稳定性。

## 修复

- 修复审批卡片中的命令内容异步高亮后与说明、执行摘要和文件卡片重叠的问题。
- 移除动态高度审批条目的列表移动动画，保证会话内容重新测量时布局稳定。
- 限制代码块绘制在自身边界内，避免延迟渲染内容影响相邻区域。
- 修复后台服务重启时可能导致的前台服务启动崩溃。
- 调整 CI 设备矩阵，使用稳定的 API 29 和 API 35 模拟器验证 Android 客户端。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.59`，versionCode `60`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.58`。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
