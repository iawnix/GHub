GHub 0.1.60 接入 App Server 官方消息队列和实时引导能力，并保留旧服务端的本地队列降级支持。

## 新功能

- 支持 App Server 官方 `thread/queue/*` 队列接口，运行中的会话可排队、查看、删除和恢复队列消息。
- 支持通过 `turn/steer` 向当前活动任务发送实时引导消息。
- 旧版 App Server 不支持官方队列时，自动使用本地持久化 FIFO 队列。
- 支持编辑队列消息、断线恢复和队列发送失败后的内容保留。

## 协议与兼容性

- 队列能力按服务器协议版本动态探测，不支持新接口的服务器继续保留普通对话功能。
- 更新协议文档和客户端协议单元测试，覆盖队列和引导请求格式。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.60`，versionCode `61`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.59`。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
