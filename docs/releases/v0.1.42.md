GHub 0.1.42 优化对话阅读、代码展示和审批提示，减少重复状态信息。

## 改进

- 精简助手回复标题和已同步提示；运行中的执行摘要显示当前命令。
- 压缩命令块布局，复制按钮放在命令右侧；代码换行改为带选中状态的图标开关。
- 执行信息仅显示非零退出码，耗时以毫秒、秒或分秒展示。
- 审批卡片增加醒目标识，明确区分「允许一次」「拒绝并继续」和「中止任务」；审批或阻塞问题不在可读区域时提供固定查看入口。
- 加载历史的进度条改为叠加显示，避免推移对话内容。
- 输入框使用统一表面，停止按钮使用红色；顶栏连接圆点与连接状态标签保持一致。
- 首页对齐项目名与会话标题，并显示会话的相对更新时间；终端方向键调整为 ← ↑ ↓ → 顺序。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.42`，versionCode `43`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.41`。

发布流程检查 JVM 单元测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行，并验证正式 APK 签名。新增耗时格式单元测试，更新代码展示设备测试。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
