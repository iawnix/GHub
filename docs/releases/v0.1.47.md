GHub 0.1.47 优化服务器列表和会话 Markdown 渲染。

## 新增与改进

- 设置里的服务器列表只显示服务器名称和连接状态，IP、端口及跳板机信息保留在服务器详情页。
- Markdown 表格单元格复用正文的 Compose 渲染组件，表格中的链接、行内代码和强调样式保持一致。
- 继续使用 Compose 原生会话渲染和分块懒加载，避免引入 WebView 带来的滚动、流式更新和主题同步复杂度。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.47`，versionCode `48`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.46`。

发布流水线会检查 JVM 测试、Lint、API 29/35/36 设备回归、API 35 精简 Release 运行和正式 APK 签名。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
