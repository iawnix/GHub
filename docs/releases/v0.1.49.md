GHub 0.1.49 优化会话正文中的行内代码显示。

## 新增与改进

- 移除行内代码的深色胶囊底色和圆角背景，字段名、参数名与正文之间的阅读节奏更自然。
- 保留等宽字体，继续区分代码和普通文本。
- fenced code block 仍使用独立代码块表面，不影响代码阅读和复制。
