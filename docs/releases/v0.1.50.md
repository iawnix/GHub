GHub 0.1.50 新增会话数学公式渲染。

## 新增与改进

- 支持 `$…$`、`\(…\)` 行内公式和 `$$…$$`、`\[…\]` 独立公式，可显示分数、上下标、根号、求和、积分及矩阵。
- 公式采用原生绘制，可离线使用，适配深浅主题和系统字体大小，并支持与列表、表格混排。
- 宽公式支持横向滚动，独立公式提供 LaTeX 源码复制；整条回复的复制和分享继续保留原始 Markdown。
- 流式输出中未完整的公式、语法错误或不支持的内容保留源码；已完成公式在后台排版并缓存。
- 修复美元价格文本被底层 Markdown 解析器吞掉的问题，代码和链接地址中的公式标记保持原样。

公式渲染不支持完整 LaTeX 文档、全局宏定义和外部图片；超出长度、嵌套或绘制尺寸限制时显示源码。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.50`，versionCode `51`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.49`。

发布前已通过 68 项应用单元测试、公式与 Markdown 流式设备专项、Lint 和精简 Release 运行检查。发布流水线还会执行 JVM 测试、API 29/35/36 设备回归、API 35 Release 运行与正式 APK 签名验证。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
